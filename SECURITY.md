# Security Policy

## Supported versions

Only the latest release of this extension receives security fixes. Please update to the newest release before reporting.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately via GitHub: go to the **Security** tab of this repository and click **Report a vulnerability**
(or use https://github.com/AxelHamburch/zapbox_extension/security/advisories/new).

Please include:

- the affected version
- a description of the problem and its impact
- steps to reproduce, if possible

You will get a first response as soon as possible. Fixes are released as a new version, and the report is credited
in the advisory unless you prefer to stay anonymous.
